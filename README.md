# 项目共享仓库

云上Hermes和本地Hermes共享的脚本、工具、文档。

## 目录结构

```
projects/
├── scripts/
│   ├── cron/          # 定时任务脚本（青龙面板等）
│   └── tools/         # 工具脚本
├── docs/              # 文档和笔记
├── skills/            # Hermes skill 文件
└── README.md
```

## 使用规则

1. **文件命名**：简短、语义化、中文
2. **提交信息**：写清楚干了啥
3. **敏感信息**：不要提交 token/密码到仓库
4. **同步方式**：push 后另一台 pull 即可
