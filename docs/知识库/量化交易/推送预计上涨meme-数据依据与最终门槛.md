# v4 的数据依据（6704 样本实测）

**决定性的一行对比：**
```
净流入>$1000 且 交易者>20   →  中位 −40.4%，跌50%+ 占 41.5%   ← 顶部特征
净流入>$1000 但 交易者≤20   →  中位 +0.1%，跌50%+ 占 0.0%    ← 唯一不为负的组合
```

**"钱在进、但还没引来一堆人"就是启动前的形态。**

其余支撑数据：
```
发币后涨 20~50%  →  之后砸 −47.5%，赚的比例 0%
发币后涨 100%+   →  之后砸 −66.0%
发币就买         →  中位 −21.1%
+15 分钟再进     →  中位 −0.5%（唯一稳定减亏动作）
首分钟买家 ≥50   →  有成交率 71%（基准 5.9%）——唯一有效的"能不能进出"指标
```

# 最终门槛（bsc_chain.py）

```
硬闸一  LP 未锁/未知 → 不推，无任何例外
硬闸二  从池子开盘算涨幅 > 80% → 挡追高（[挡追高]）
硬闸三  5分钟独立买家 > 20 → 挡"人太多"（[跳过-人太多]）
硬闸四  刷量分 ≥60 拦 / 40~59 降级

P 级（起飞前）通过条件：
  池龄 ≤120min · 流动性 ≥$25K · 1分钟买 ≥8笔
  净买 ≥max($1500, 流动性×2%) · 最大单笔 ≥$800
  独立买家 5~20 个 · 涨幅 ≤80%（从开盘算）
```

# 实现细节（改动点）

- `Pool.__slots__` 加 `init_ratio`（**用 `__slots__` 的类加字段必须同步加进 slots**，否则赋值抛 AttributeError）
- `Pool.gain_pct()`：用储备比算涨幅 `(计价/代币)_now ÷ (计价/代币)_init − 1`
- `register_pair()` 建池时记录 `init_ratio`（建池瞬间的储备比 = 开盘价基准）
- 快照 `save_snapshot`/`load_snapshot` 同步存取 `init_ratio`（否则重启丢基准）
- 挡追高的 RPC 只在"池龄和流动性已过门槛"时才调，省配额
