**crypto 是强趋势资产，赚钱靠顺势跟随 + 拿得住，不是抄底。** 均值回归类策略（RSI 超卖买）在 4h 级别是负期望，调参数没用，方向反了。

## 为什么均值回归在 crypto 必死

- 股票有均值回归的估值锚，crypto 没有。
- 强趋势里"超卖"可以持续超卖，抄底会被趋势碾压（DOT -66%、连续阴跌）。
- 4h 级别的 RSI/MACD 组合早被套利，散户能拿到的信息已 price in；频繁交易（79 笔）被手续费吃掉。

## 踩坑记录

- **币安 API 地区限制**：`api.binance.com` 对代理出口返回 451。改用公开数据端点 `https://data-api.binance.vision/api/v3/klines`，不限制地区、不需要 key。✓
- **多因子信号不要"同一根 K 线共振"**：RSI<35 且 MACD 金叉且量能放大同时成立 → 信号数为 0。用滚动窗口（rolling(lookback).max()）表达"最近 N 根内发生过"。
- 回测能看到负收益说明没作弊。市面上 99% 技术指标策略回测都是负的。

## 非量化路径（2026-09-18 实测补充）

### 资金费率套利（低风险，已实测）

现货买币 + 永续合约等量做空，对冲掉涨跌，只吃多头付的资金费（funding rate）。

OKX 公开 API 实测（近 100 期 ≈ 33 天，2026-09-18）：

| 标的 | 均值/8h | 年化 | 正费率占比 |
|---|---|---|---|
| BTC-USDT-SWAP | 0.0058% | **6.35%** | 95% |
| ETH-USDT-SWAP | 0.0056% | 6.15% | 92% |
| SOL-USDT-SWAP | 0.0022% | 2.36% | 60% |

- 牛市费率能冲到年化 20-50%，熊市贴近 0。
- 需要本金，收益稳定但不暴利；可叠加现货质押/理财收益。
- 关键：两边仓位必须等量对冲，否则变成单边赌方向。
