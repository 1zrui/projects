# meme 涨跌规律 · 6704 样本实测（修正版）

> ⚠️ **2026-09-18 重大修正：本文件此前所有版本的价格方向搞反了，结论全部作废。以下是修正后的版本。**

## 🔴 错误记录：价格探针的符号是反的

**错误来源**：`factor_log.py` 用 `quoteExactInput(BNB→币, 0.001 BNB)` 返回的**币数量 V** 当价格代理，
然后算 `ret = V/V0 − 1` 当成"涨跌"。

**错在哪**：V 是"0.001 BNB 能买到多少币"。**币价涨 → 买到的币少 → V 变小。**
所以 `V/V0 − 1` 是**币价的倒数变化**：**ret 为正 = 币价下跌**。

**怎么发现的（对账）**：拿模拟盘真买过的 STORMII 对账——

| 口径 | 数值 |
|---|---|
| 探针：price0 = 0.001/96,393 币 | **1.037e-8 BNB/币** |
| 探针：+5 分钟后 = 0.001/265,036 币 | **3.77e-9 BNB/币**（相对 price0 −63.6%） |
| paper_trade 买入价（真实账本） | 1.333e-8 BNB/币 |
| paper_trade 现价（**卖出**报价 `quote(币→BNB)`，方向无歧义） | 3.502e-9 BNB/币（**−73.7%**） |

两条**方向相反**的独立报价得出**一致的币价** → 探针口径正确、V 与价格**反比** → `ret` 符号是反的。

**修正公式**：`真实涨跌幅 = V0/V − 1 = 1/(1+ret) − 1`

> 教训：**任何价格代理，上手前先用两个方向（买/卖）的报价互验一次方向，再拿去算收益。**
> 方向错了，后面所有分析越严谨越有害。

## 五之三、两层特征挖掘：能预测「有成交」，预测不了「涨」

把因变量拆成两层后，**第一层出现了真实、可提前使用的特征**：

### 第一层：这个币会不会有成交（基准 5.9%）

| 特征（发币时就能知道） | n | 有成交率 | 提升 |
|---|---|---|---|
| **18~19 点发币** | 750 | **10.8%** | **×1.8** ★ |
| 上币安榜 | 2282 | 8.9% | ×1.5 |
| **题材集群（同词根出现 ≥3 个币）** | 3440 | 8.0% | ×1.4 |
| 名字含中文 | 2381 | 7.9% | ×1.3 |
| 观测时 ≤3 分钟 | 3174 | 7.2% | ×1.2 |
| 名字 ≤4 字 | 3413 | 6.8% | ×1.2 |
| 名字 ≥15 字 | 642 | **0.0%** | ✗ 直接排除 |
| 12 点 / 23 点 / 21 点发币 | 1421 | 2.8~3.8% | ✗ 最差 |

**组合**：题材集群 + 14~19 点 + ≤4 字 → **11.0%（×1.9）**

**"题材集群"是本轮新发现**：同一时段冒出多个同词根的币（蝴蝶系列、功夫猫、ipos、功夫小蝇…），
有成交率 40~60%（基准 5.9%）。含义：**有人在批量制造这个题材 = 真有人在玩这个梗。**

### 第二层：有成交的里面，涨还是跌 —— 现有数据挖不出来

| | n | 占比 | 中位 |
|---|---|---|---|
| 有成交的币 | 352 | 5.9% | −21% |
| └ 其中涨的 | 21 | **6.0%** | +33.8% |
| └ 其中跌的 | 331 | **94.0%** | −22.4% |

所有特征组合的"涨 10%+ 概率"都只有 **0.41% ~ 0.50%**（基准 0.35%）—— 提升微乎其微。

**原因不是"特征不存在"，是两个硬伤：**

1. **正样本太少**：5986 个里只有 21 个涨 10%+。
   **21 个样本找不出可靠特征** —— 至少需要 200~500 个正样本 → 对应采集 6~15 万个币
   （按当前 549 个/小时，需要 5~11 天）
2. **采的特征不对**：现在用的全是**滞后观测**（币安榜的净流入/交易者数，等上榜时价格已经拉完）。
   真正该采的是**发币瞬间就能拿到的链上行为**。

### 缺失的特征清单（一个都没采，优先级从高到低）

```
① 发币第 1 分钟的独立买家数（链上实时，不是 5 分钟榜数据）
② 首个买家身份：狙击机器人 / DEV 自己 / 聪明钱地址
③ LP 锁仓状态 —— 现在完全没采，而这是"能不能被抽跑"的唯一决定指标
④ 合约权限：能否改税 / 增发 / mint
⑤ DEV 历史：这个地址发过几个币、之前那些币后来怎么样
⑥ 前 1/3/5 分钟的买卖笔数曲线（现在是单点快照）
⑦ 持币分布的变化速度
```

### 结论

> **现有数据能用出第一层（筛掉 94% 的零成交死盘），用不出第二层（选出会涨的）。**
> 要找出"该买"的特征，必须**把上面 7 条特征采全 + 样本量放大 20 倍**。

只用「有成交」的 352 个币（其余 96% 根本没成交，买都买不进）：

> **不是"等 10~30 分钟"就自动好，而是：等 10~30 分钟，买那些「没暴拉过、抛压释放完、价格站住」的。**

### ③ ⚠️ 但它不预测方向 —— 活跃度越高，跌得越狠

把活跃度门槛和进场时点交叉（持有到 60 分钟）：

|---|---|---|---|---|

**关键结论：**
1. **链上活跃度 = 波动率指标，不是方向指标。** 它把"暴涨概率"从 0.35% 提到 5%，但同一批币的中位收益是 **−30.9%**（发币买）——**高波动彩票，多数暴跌**。
2. **越活跃跌得越狠**：首分钟买家≥50 → 发币买 −30.9%；5分钟买家≥200 → 发币买 **−61.1%**。
3. **唯一能把亏损收窄的还是「晚进场」**：+15 分买把 −30.9% 收到 −1.8%。
4. **但期望仍然是负的** —— 最好的组合（首分钟买家≥20 + 15 分买）中位 −0.2%，赚的比例 28.3%。

### ④ 所以现在的完整认知

```
发币首分钟链上活跃度  →  决定「能不能进得去、出得来」（过滤死盘，5986 → 201）
动量/涨幅位置        →  决定「追涨必死」（早期涨20%+的之后砸 -42%~-66%）
晚进场（+15分钟）     →  唯一稳定减少亏损的动作（-30.9% → -1.8%）
方向（涨还是跌）     →  ❌ 现有特征全都预测不了，期望仍为负
```

**下一步该采的**：能预测「方向」的特征 —— 首个买家身份（狙击机器人/DEV/聪明钱）、DEV 历史发币记录、LP 锁仓状态、合约权限。这些现有回填里都没有。

### ① 「合约权限」这条特征废掉

Flap 的币**全是 EIP-1167 克隆合约（45 字节）**，抽出的 implementation **全都是同一个** `0x024f1829…6422`（Tax Token V3 模板）→ **所有币共用同一套权限逻辑，没有区分度**。别再在字节码里找权限特征。

### ② 「首个买家地址年龄」看起来有效，但拆开后是反的

**表面看（含全部样本）：**

| 首买家 nonce | n | 均值(+15分买) | 赚的比例 |
|---|---|---|---|
| 1 分钟内无真实转账 | 4598 | −0.0% | 24.1% |
| 1~5（全新地址/机器人） | 1025 | −2.2% | 35.0% |
| 51~500 | 57 | −1.1% | 43.9% |
| **500+（活跃老地址）** | 290 | **+2.2%** | **45.5%** |

**拆到「有成交」子集后（这才是真实收益）：**

| 组合 | 有成交 n | 中位 | 均值 | 赚的比例 |
|---|---|---|---|---|
| 老地址首买(500+) | 34 | **−3.0%** | +17.4% | **18%** |
| 老地址首买 + 首分钟买家≥20 | 12 | −4.7% | +69.2% | 17% |
| 老地址首买 + 5分钟买家≥50 | 15 | −5.0% | +48.3% | 13% |
| 首分钟买家≥50（不论谁买） | 81 | −6.3% | −16.8% | 16% |
| **无真实首买家** | 72 | **−0.0%** | −3.8% | **40%** |

**关键：**
1. **均值全是被极值拉飞的** —— 中位数全是负数，赚的比例只有 13~18%（样本 12~34 个，一个暴涨币就能拉动均值）。
2. **「有活跃老地址抢着买」= 热度 = 更接近顶部** —— 与前面"热度是反向指标"完全吻合。
3. **"无真实首买家"那组赚的比例 40% 最高，但 4598 个里只有 72 个有成交（1.6%）** —— 也就是"根本没人交易的币"，你买进去也卖不掉。

### ③ 阶段性总账（诚实版）

```
✅ 有效：链上首分钟活跃度 → 筛「能不能交易」（有成交率 5.9% → 71%）
✅ 有效：晚进场（+15 分钟）→ 减亏（发币买 −21.1% → +15分买 −0.5%）
❌ 无效：所有「方向」类特征 —— 净流入 / KOL / 持币数 / 合约权限 / 首买家身份
        细分后中位一律 ≤ 0，赚的比例 13~40%
❌ 反向：热度类特征（越热越接近顶部）
```

**结论：用目前能采到的链上数据，「方向」挖不出正期望。** 想再往前走，需要的是**能改变赔率结构**的东西（不是再加特征）：
- 只在「明确的叙事 + 极短窗口」出手（当前数据里没有这类样本）
