# 核心结论

**BSC 上 Pancake 池的 meme，LP 锁定率实测为 0%**（抽查 10 个主流池、含流动性 $132 万的）。
所以「LP 锁了才推」这个门槛 = **永远不推**；而「LP 未锁也推」= **推诈骗**。

**唯一结构上安全的位置是发射台曲线阶段（未毕业）**：代币与储备由发币合约托管，
发币人自己抽不走。这是 bBALL（12 分钟涨 6.5 倍没被抽干）和 🐰GANG（一抽归零）的差别所在。

# 三次实测证据（血的教训）

| 币 | LP | 结果 |
|---|---|---|
| 🐰GANG `0x94c0…73b1` | **0% 未锁** | 04:33 推出去时池内 **$50,067**，之后被一次性抽到 **$0.82**（99.997%） |
| BREW / 神股 / 妹妹 | 0% 未锁 | 推送后全部回落（放开闸那轮 24h 推了 84 条这类） |
| bBALL `0xed7e…7777` | **100% 黑洞销毁** | 12 分钟涨 6.5 倍、$92 万成交、1755 买客，结构完好 |

**「流动性 ≥$50K 就放行未锁盘」这个例外是致命错误** —— 骗子会故意把池子做厚让你觉得安全，
然后一次性抽干。**已彻底删除该例外。**

# 复用要点

1. **LP 未锁的盘不要用"流动性够大"来放行** —— 那是最容易被精心设计的陷阱。
2. **判断"能不能买"要看结构位置**（曲线上 / 已毕业且锁 LP / 已毕业未锁），不是看涨幅和筹码。
3. **筹码分散不预测涨跌**：🐰GANG 前十仅 7.06%、最大单一 1.3%、542 个持币地址 —— 照样被抽干。
4. **持有 79% 的 `0x…dead` 是 Flap 的销毁机制**（曲线没卖完的部分），不是庄家；
   别把它当成"巨鲸持仓"去吓自己或吓用户。**算占比时 balanceOf 的原始值要除以 decimals，
   分母别用 totalSupply 的原始 wei**（实测踩过：790,000,000 枚被算成 0.00%）。
