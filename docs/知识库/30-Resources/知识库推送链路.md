# 知识库推送链路

> 摘要：知识库真正对外发布的仓库是 `projects`（github.com/1zrui/projects.git），不是 `~/workspace/知识库` 本地 git。

## 现状
- `/home/ubuntu/workspace/知识库` 有自己的 git 仓库，但**未配置任何 remote**，`git push origin` 会报错
- 真实备份/推送路径：`/home/ubuntu/workspace/projects/docs/知识库` → `git push origin`（github.com/1zrui/projects.git）
- 巡检/入库流程：写完笔记 commit 到主知识库 → 复制新文件到 `projects/docs/知识库/` 对应目录 → projects 仓库 `git add -A && commit && push`

## 注意
- 若 push 报代理错误，先 `unset HTTPS_PROXY http_proxy https_proxy` 再推
- `projects/docs/知识库` 里有一个陈旧嵌套 `.git`（HEAD 停在 09/24、无 remote），不要动它，同步文件即可
