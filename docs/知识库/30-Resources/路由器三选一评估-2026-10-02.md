# 路由器三选一评估（2026-10-02）

> 摘要：大哥拿来三款候选（TP-LINK XDR3010 / 小米 BE3600 2.5G / 中兴巡天 AX3000）。结论：**小米 BE3600 2.5G（159–179）配置最高、带 2.5G 口，首选**；**中兴巡天 AX3000（130–159）**是"只要稳、不折腾"的选择；**XDR3010 跳过**（2021 老平台 + 16MB 闪存 + 多次减配）。另：之前推荐的 **小米 AX3000T 已因换 SOC/交换芯片不再推荐**。

## 结论（2026-10-02 修正版：按实测数据重排）
大哥指出"网上没人推荐小米"，核实后**他是对的** —— 上一版我按规格表给了小米加分，实测数据不支持。修正如下：

### 实测证据（关键）
- **腾讯 2026-02 八款百元 WiFi7 横评**：小米 BE3600 满载贴脸平均速率**只有 1.6Gb**（区间 1.5–1.9Gb），其余主流机型 2.1–2.3Gb；且**满载温度最低**（作者评价"在这摸鱼偷懒"）。该文总结直接写：**"这个价位不太推荐腾达和小米全系"**，只留普联 7DR3630/7DR6430、中兴 BE3600Pro。
- **知乎三款横评（TP-LINK 3630 / 华为 BE3 Pro / 小米 BE3600 2.5G）**：近距离三者差距不大；**测试点远离路由器后，5 天线的 TP-LINK 3630 优势明显扩大**（联发科 MT7976CN + MT7991BV + Xtra Range 2.0）。小米拆机堆料其实不差（IPQ5312 四核 + 256MB + 散热好），但无线调教偏弱。
- **B 站/海外口碑**：多个评测标题为"别买小米路由器 BE3600""信号覆盖能力不太行""价格上是卷王，实际一言难尽"；Reddit 用户反馈 5G 频段衰减严重、信号差。

### 三款重排
| 排序 | 型号 | 定位 | 关键依据 |
|---|---|---|---|
| **1（同级最稳）** | 中兴巡天 AX3000 | 三星里唯一没有明显短板 | 自研双核 + 硬件转发引擎，穿墙/稳定口碑最好，价格最低；短板是 WiFi6 + 全千兆 |
| 2（有线党特供） | 小米 BE3600 2.5G | 只有你需要 2.5G 口/NAS/2000M 宽带时才选 | 规格最高（WiFi7+MLO+四核+2.5G 口），但**无线实测垫底、覆盖率差** |
| 3（跳过） | TP-LINK XDR3010 | 不建议 | 2021 老平台 IPQ0509、**闪存仅 16MB**、多次减配 |

### 真正的最优解（如果预算能加 30–50）
**TP-LINK 7DR3630（BE3600，~169–199）**：5 天线（3×5G）、联发科 MT7976CN + MT7991BV、512MB 内存、1×2.5G + 3×千兆 —— 上述八款横评里表现最好的一台（能长时间稳定跑满 2.5Gb），也是知乎横评结论的"性价比之王"。想要信号更好可上 **7DR6430**（5G 4×4 MIMO + 外置 FEM，~257）。

### 一句话决策
- 只求稳、要穿墙、最省钱 → **中兴巡天 AX3000**
- 有 NAS / 要上 2000M 宽带、只在乎有线 → 小米 BE3600 2.5G
- 能加钱、要同价位最均衡 → **普联 7DR3630**（强烈建议）
- XDR3010 → 无论哪种都别买

## 评测数据汇总（2026-10-02 第二次补充：逐台实测/拆机）
> 来源优先用拆机与实测（acwifi 拆机、B站进贰《值不值得买》、腾讯/知乎八款横评、B站 opus 实测数据）；smzdm 上的 AI 聚合文不采信。

### 普联 7DR3630（BE3630，189 元）
- 拆机：**达发 AN7563PT 双核 A53 1GHz + 集成 NPU**；5 天线（3×5G + 2×2.4G，三振子，角度可调）；4 口（1×2.5G + 3×千兆，全盲插）；512MB 内存 + 128MB 闪存；12W 电源
- 实测吞吐：5G 单终端最高 **1825Mbps**；开 MLO **1846Mbps**（提升小但稳定性更好）；多口双向打流 3666Mbps
- 组网：易展 15 秒配对，最多 8 台；Mesh 漫游 18 次 **0 丢包**，平均切换延迟 58.5ms
- **短板**：① 抗干扰差（强干扰下上传掉一半以上）② **单台只适合小户型**，穿墙衰减明显（开 MLO 穿一堵墙无压力，远距离必须组网）
- 八款横评：**性能最强 + 满载功耗最低**（达发 6nm 能效最好）

### 中兴 AX3000 巡天（126 元）
- 拆机（acwifi）：自研双核 1GHz + 硬件转发引擎；256MB 内存 + 128MB 闪存；射频 MT7976DN；**待机 5.3W**
- 口碑：同价位**穿墙/信号第一梯队**；用户对比华为 AX3 Pro 后评价"连开一周只是温温的"（发热控制更好）
- 弱点：WiFi6、全千兆；隔 3 堵承重墙 5G 同样基本不可用（所有单台路由通病）

### 小米 BE3600（千兆 149 / 2.5G 171）
- 八款横评：**满载贴脸 1.6Gb 垫底**（同场 2.1–2.3Gb），满载温度最低（作者评"摸鱼偷懒"）；覆盖与主流一档
- 知乎三款横评：近距离差距不大，**测试点远离后 5 天线的普联 3630 优势扩大**
- 拆机（acwifi）：空口 4.4W（黑版）/ 6W（白版），**接 2.5G 口 7.9W**；硬件堆料不差（IPQ5312 四核 + 256MB + 散热好）

### TP-LINK XDR3010（132 元）
- 拆机：**闪存仅 16MB**、IPQ0509 双核 1GHz、2021 年 8 月平台、不可刷机
- B 站实测标题即结论：**"缩水四次"、"减配！选购要小心"、"从高性价比到性能弱鸡"**；有用户连买两台测 3 天发现"根本不是一个东西"（批次差异巨大）
- → **无论什么场景都排除**

## 功耗（2026-10-02 补测：acwifi 拆机实测）
路由器是 24h 常开的设备，功耗要算进来。实测值：

| 机型 | 电源规格 | 实测功率 |
|---|---|---|
| 小米 BE3600 **黑版** | 12V/1A | 空口 **4.4W** → 接千兆 WAN **4.7W** |
| 小米 BE3600 **白版** | 12V/1.25A~1.5A | 空口 **6W** → 接千兆 6.4W → **接 2.5G 口 7.9W** |
| 中兴巡天 AX3000（WiFi6） | — | 待机 **5.3W** |
| 中兴巡天 BE3600Pro | 12V/1A~1.5A | 空口 4.4W → 接 2.5G **5.3W** |
| 小米 BE3600 Pro | 12V/1.5A | 空口 5.4W → 接 2.5G 7.4W |
| TP-LINK 7DR7230 | — | 接 2.5G 7.0W |
| TP-LINK **7DR3630** | — | 八款横评中**满载功耗最低**（同场性能最强） |
| TP-LINK XDR3010 | 12V/1A | 未找到可信实测，按同代平台估 5–6W |

**折算电费**（0.55 元/度，24h×365）：
- 4.4W → 38.5 度/年 ≈ **21 元/年**
- 5.3W → 46.4 度/年 ≈ **25 元/年**
- 6.4W → 56.1 度/年 ≈ **31 元/年**
- 7.9W → 69.2 度/年 ≈ **38 元/年**
- **5W vs 8W 一年只差 26 度 = 14.5 元** → **电费本身不影响决策**

**功耗真正影响的是两件事**：
1. **发热 → 稳定性/寿命**：低功耗 = 机器凉 = 夏天不降频、不断流（很多"断流"投诉根源就是热）。
2. **重度用法会被放大**：插 2.5G 口普遍 +1~3W；刷机跑插件（青龙/科学/PCDN）CPU 长期负载，MT7981B 可到 6–8W，且风扇/散热差的机型容易趴。

**结论修正**：普联 **7DR3630 = 性能最强 + 功耗最低**（能效比最好，24h 开最划算）；**中兴巡天 AX3000 5.3W** 也很省；**小米 BE3600 白版接 2.5G 口 7.9W 是这几款里最费电的**，且黑/白版（1A vs 1.25A 电源）功耗差 30%，买前务必确认版本。

## 结论
1. **小米 BE3600 2.5G —— 首选**。贵 20-30 块买到的是代差：四核 CPU、WiFi7 + MLO、128MB 闪存、**2.5G 网口**（未来升 2000M 宽带/接 NAS 有余量）。
   ⚠️ 短板：2026-02 的 8 款百元级 WiFi7 横评实测里，小米 BE3600 的**无线表现偏弱**（同价里垫底）—— 它的价值在"有线 + 规格"，不在信号极限。
2. **中兴巡天 AX3000 —— 稳字优先**。自研双核 + 硬件转发加速引擎，穿墙口碑最好，EasyMesh 组网，价格最低。缺点：WiFi6、全千兆。
3. **XDR3010 —— 不推荐**。2021 年平台、**闪存只有 16MB**（连插件都塞不下）、历史上多次减配、社区评价"想不开/不建议购买"。同价位 TP-LINK 自家 XDR3030（MT7981B 双核 1.3GHz）比它强。

## 顺带更正（重要）
**之前推荐的「小米 AX3000T」现在不要再买** —— 2026 年拆机/横评确认它**先后更换了交换芯片和 SOC**（V2 由 MT7981B 1.3GHz 换成高通 IPQ5018 1.0GHz），已从"性价比之王"变成不推荐。
