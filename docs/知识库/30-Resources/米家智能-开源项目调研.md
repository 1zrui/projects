## 〇、小米官方项目（XiaoMi / MiCode / MiEcosystem 组织，2026-10-06 实测）

小米官方 GitHub 组织共 83 个公开仓库，**跟米家智能真正相关的只有两个**；其余（soar、mace、open-falcon、Gaea、naftis、MiNLP、MiLM-6B…）是数据库/推理框架/监控/大模型，与米家无关。`MiCode` 组织 80 个仓库全是手机系（MIUI 内核、便签、文件管理器），**跟米家无关**。

### 1. XiaoMi/xiaomi-miloco ★★★ 官方全屋智能 AI，原生支持 Hermes Agent

- **3391 ★** | 2025-11-06 建仓，2025-12-17 开源 | Python | 2026-09-22 最后更新 | **非商业许可**
- 全称 **Xiaomi Local Copilot**：米家摄像头的画面+声音做全模态感知入口 → 自研 **MiMo 大模型**做大脑 → 以 **Agent 插件**形式运行在 [OpenClaw](https://openclaw.ai) 之上，联动全屋设备做主动智能
- Miloco 2.0（2026-06-18）重构为插件：通用常识、身份识别（人脸/体态）、家庭记忆、家庭任务、主动智能、家庭面板
- **v2026.7.17 新增「Hermes Agent 兼容层（可插拔 agent runtime）」** — README 明确写「适用于 OpenClaw 和 Hermes Agent」
- 仓库结构：`backend/`(感知引擎+MIoT SDK) `cli/`(miloco-cli) `plugins/`(openclaw 插件 + skills) `web/`(家庭面板) `knowledge/`

**安装（装给 Hermes Agent）：**
```bash
curl -LsSf https://github.com/XiaoMi/xiaomi-miloco/releases/latest/download/install.sh | bash -s -- --agent-platform=hermes
```
（不加 `--agent-platform=hermes` 默认装给 OpenClaw；也可让 Agent 自己读 `scripts/install-guide.md` 安装）

**装完：**
```bash
openclaw gateway restart          # 重启网关让插件生效
miloco-cli dashboard              # 家庭面板 → http://<host>:1810/
miloco-cli config set model.omni.api_key sk-xxx
miloco-cli account bind           # 绑定小米账号，自动拉取米家设备
miloco-cli scope camera enable <did>
miloco-cli doctor                 # 自检（WSL 环境会查防火墙/网络）
```

**前置条件与成本（务必记住）：**
- 硬件：内存 ≥ 4GB、存储 ≥ 256GB、7×24 常驻，**推荐 Mac mini**
- 系统：macOS / Linux；**Windows 不支持原生，必须 WSL**
- 需要 **OpenClaw / Hermes Agent** 作为 runtime（需 ≥ 2026.5.2）
- 需要小米账号 + 已接入米家的设备 + **多模态大模型 API Key**（推荐小米 MiMo：感知 `MiMo-v2.5`、Agent `MiMo-v2.5-pro`）
- ⚠️ **持续烧钱**：感知与 Agent 主要依赖云端大模型，token 费按用量跑，面板「模型」页可看消耗
- ⚠️ **WSL 额外坑**：默认 NAT 会拦摄像头发来的 UDP 包，实时画面加载不出 → 需 `networkingMode=mirrored` + 管理员放行 Hyper-V 入站
- ⚠️ **许可**：仅供非商业使用，未经小米书面授权不得用于开发 App / Web 服务

## 四、结论：给 Hermes 接入的推荐路径

0. **要走小米官方路线 → 直接上 XiaoMi/xiaomi-miloco**（原生 Hermes Agent 兼容层，官方一条命令）。前提是接受：WSL/macOS/Linux 部署、摄像头做感知入口、MiMo 云端模型持续计费、非商业许可。

1. **首选 Do1e/mijia-api**：扫码登录走米家云端，不用刷机、不用 Home Assistant、不用设备 token。一个 pip 包 + Hermes 挂 MCP 就能做到「汤圆，把客厅灯关了」。
2. **要小爱音箱播报** → 加 xvhuan/xiaoi（Webhook/MCP 一键播报）。
3. **要最强生态/自动化联动** → 单独跑 Home Assistant + XiaoMi/ha_xiaomi_home（官方）。
4. **要本地控制、不要云端** → python-miio + 提 device token（折腾成本高）。

## 五、踩坑备忘

- 米家云端登录会有**异地登录安全验证**，容器里跑要额外补 passToken / 处理验证。
- passToken、米家账号密码、模型 Key、TTS Token 都是敏感凭据，**不要写进文章、截图或公开仓库**。
- 云端方案依赖小米官方接口，接口变更即失效；本地 miIO 方案不受影响但要 token。
- 小米账号风控：频繁登录/多 IP 可能触发验证，容器持久化 `~/.config/mijia-api/auth.json` 避免重复登录。
