# 中联 ZLSoft 电子病历客户端配置 — 加密结构与批量部署

> 摘要：中联（ZLSoft）电子病历客户端配置文件结构、加密方式实测结论，以及批量替换配置文件的部署方案。2026-09-11 实测。

## 一、配置文件构成

| 文件 | 作用 | 是否明文 |
|---|---|---|
| `ClientServerSetting.config` | 应用服务器地址 `<HOST>IP:9093</HOST>` | ✅ 明文 |
| `config_zldoc.xml` | 病历文档库连接 `<DbSource>` | ❌ 加密（DES/3DES）|
| `userid` / `password`（同在 config_zldoc.xml） | 数据库账号 | ❌ 加密，8 字节密文 |

配置文件目录里通常同时存在 `XXX - 副本` 形式的备份，可作为新旧对比样本。

## 二、加密方式实测结论（2026-09-11）

样本：`DbSource` 新串 vs 旧串（服务器 172.16.100.21:9093 → .88；数据库 .11 → .99）

| 观察 | 结论 |
|---|---|
| userid/password base64 解码 = **8 字节** | 算法是 **DES / 3DES**（8 字节分组），AES 不可能（要 16 字节）|
| DbSource base64 解码 = **256 字节**，两串**前 64 字节完全相同**，之后 192 字节**全部不同** | **CBC 链式加密**（ECB 只会差异块不同；RSA 无公共前缀）|
| 变化起点 = 明文偏移第 64 字节 | 说明连接串前半段（驱动/协议部分）未动，改动落在后面的"地址段"|

**密钥位置**：不在配置文件里，硬编码在客户端 DLL（`ZLSoft.Common.dll` / `ZLSoft.BusinessHome.Plugin.NewSDoc*.dll` 一类），需反编译提取。

**弱密钥测试**：用 ZLSoft / ZLHIS / zldoc / 中联拼音 / 年份等 111 个常见候选跑 DES+3DES ECB/CBC 解密 → **未命中**，非弱口令。

## 三、批量替换部署方案

### 前置验证（必须先做，否则全量推广会翻车）
1. **密文是否跨机器通用** — 把样板机的两个配置文件拷到另一台空机，验证能否连上。若密文与机器绑定，必须用配置工具逐台生成。
2. **是否只需改 HOST** — 客户端可能启动时从应用服务器下发配置。先只替换 `ClientServerSetting.config`，启动后看 `config_zldoc.xml` 是否被自动更新。若会 → 批量只需推 1 个明文文件。
3. **确认受影响的全部文件** — 配置工具可能同时改了其他模块配置（`config_zl*.xml`）。

### 脚本工具（`~/workspace/zl-tools/`）
- `扫描中联配置.bat` — 全盘定位配置文件、列出最近改动文件、列出运行进程
- `替换中联配置.bat` — 自动定位 + 备份（带时间戳）+ 替换 + 清缓存

用法：把改好的配置放进脚本同目录 `new\`，在目标机双击运行。

### 坑
- 客户端不关会文件锁，替换失败 → 脚本先 taskkill
- `AppData` / 客户端目录下可能有缓存副本
- 多模块分别有配置文件
- 域环境用登录脚本 / 组策略推送最快；无域则共享目录 + 批处理
