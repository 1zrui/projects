## 一、TTS 语音配置（汤圆开口说话）

### 选型过程
- **edge 晓晓**（微软,免费）：能说中文但合成感强,用户要更真人的
- **Gemini TTS**（Google,免费档）：真人感好 → **最终选定**
- KittenTTS：装包依赖多被否
- MiniMax：付费,未考虑

### 关键坑位（折腾记录）
1. **Gemini 地域限制**：直连 000,走代理后报 "User location is not supported" —— 代理出口 IP 地区被 Google 拒,换节点解决
2. **Gemini 需要代理**：直连不通,必须走 v2raya(127.0.0.1:20171)
3. **网关进程不带代理**：Hermes 网关(systemd user 服务)默认无代理环境变量,TTS 调用失败
   - 解决：写 systemd drop-in `/home/ubuntu/.config/systemd/user/hermes-gateway.service.d/proxy.conf` 加 `HTTPS_PROXY`/`HTTP_PROXY`
4. **网关重启被自保护拦截**：会话内 `hermes gateway restart` 被拒(设计如此,防自杀循环)
   - 解决：VNC 终端执行 `env -u _HERMES_GATEWAY hermes gateway restart`
   - ⚠️ 副作用：重启波及 systemd user 会话,VNC 桌面崩了,需手动 `vncserver :1 -geometry 1600x900 -depth 16 -localhost no` 拉起
5. **Gemini 免费档限流**：10 次/分钟（generate_content_free_tier_requests）,试音色频繁会 429,等 30s 恢复

## 二、网际快车订阅 → v2raya 导入问题

### 问题
订阅 URL `https://wjkc66.vip/api/subscript/v2box/...` 在 v2rayN 能用,v2raya 更新订阅失败

### 根因
1. **订阅源要求 UA**：裸请求(无 UA)返回 400,需带浏览器 UA
2. **返回明文 vless 文本**（46 节点,一行一个）—— v2rayN 兼容,v2raya 只认 base64

### 解决
- 转换脚本 `/home/ubuntu/scripts/sub_convert.py`：带 UA 拉取 → 自动检测/解码 → base64 编码 → 存本地文件
- 输出：`/home/ubuntu/v2raya_sub.txt`（base64,46 节点）、`/home/ubuntu/v2raya_nodes.txt`（明文）
- v2raya 面板可用 file:// 或本地 HTTP 导入

### 节点概况
46 个节点：新加坡/香港/日本/台湾/美国/欧洲多国,分 AWS/电信/直连/家宽/原生 IP 等,消耗倍数 1-5 倍。
订阅流量:已用 ~587M / 总 64.5G。
