## 二、⭐ 币安钱包 Web3 接口（本期最大发现）

**这是最关键的一块** —— 币安钱包的数据源，**和大哥手机上看到的口径完全一致**，免密钥、直连可用。

### 热点主题榜（叙事 → 标的）

```bash
GET https://web3.binance.com/bapi/defi/v2/public/wallet-direct/buw/wallet/market/token/social-rush/rank/list/ai
    ?chainId=56&rankType=10&sort=10&asc=false
Header: User-Agent: binance-web3/1.1
        Accept-Encoding: identity
```

- **`chainId=56` 才是 BSC** ⚠️（`CT_501` 是 Solana，会返回 pump.fun 的币 —— 踩过）
- `rankType` 取 10 / 20 / 30 可拿到 30~110+ 个热点主题
- 直连即可，无需代理

**返回结构**：热点主题 → 蹭该热点的币列表

- 主题字段：`topicNameCn` / `topicNameEn`（如"疑似Xenocortical Mouse代币"）、`topicLink`（**X 原帖链接**）、`tokenSize`、`type`、`createTime`
- 币字段（**极其丰富**）：
  ```
  资金面    netInflow / volumeBuy / volumeSell / netInflow1h / volume1hBuy / volume1hSell
  活跃度    uniqueTrader5m / 1h / 4h / 24h、count5m / 1h / 4h / 24h
  行情      marketCap / liquidity / priceChange24h
  结构      devHoldingPercent（庄家）、sniperHoldingPercent（狙击）、
            insiderHoldingPercent（内幕）、smartMoneyHoldingPercent（聪明钱）
  喊单      kolHolders（哪些 KOL 持仓 = 有人在喊）★ 这是"喊单加持"的答案
  状态      protocol、migrateStatus（曲线毕业没）、holders
  ```

**用它解决了四个老难题**：
1. 曲线阶段的币看不见 → 币安全程跟踪（含 `migrateStatus`）
2. 叙事→标的映射（原来是手工做的）→ 热点榜直接给
3. "推特有没有人喊"查不到 → `kolHolders` + `topicLink`（X 原帖）
4. 庄家/狙击占比要自己算 → 字段直接给

**已验证的用法示例**：
- `WOLVERINE 0x1dbec90600d65cd3db835a57d45bfc02dfe27777` → 挂在热点【Esoteric批评《漫威金刚狼》游戏】，X 原帖 `x.com/esotericpigeon/status/2100266469002990064`，净流入 +$2,945，庄家 0%，内幕 0.26%，KOL 0
- 判断"是不是正主"：币安热点榜里跟的地址 vs 你收到的地址 → **不在榜上 = 同名仿盘**（如 `Mouse 0xab035374…7777` 就是仿盘，币安跟的是 `0x0d81ea…` / `0x2082ce…`）

### 交易函数（Portal 上调用）

```solidity
// 报价（不需要发交易，eth_call 即可）
struct QuoteExactInputParams { address inputToken; address outputToken; uint256 inputAmount; }
function quoteExactInput(QuoteExactInputParams calldata params) external returns (uint256 outputAmount);
// selector: keccak("quoteExactInput((address,address,uint256))")[:4] = 0xfc847c2b

// 成交
struct ExactInputParams {
    address inputToken;      // 买：address(0) 代表 BNB；卖：填币地址
    address outputToken;     // 买：填币地址；卖：address(0) 代表 BNB
    uint256 inputAmount;
    uint256 minOutputAmount; // 滑点保护
    bytes permitData;        // 可空（空则需先 approve）；填 permit 可省一笔授权交易
}
function swapExactInput(ExactInputParams calldata params) external payable returns (uint256 outputAmount);
```

**手续费**：协议费 1% + 代币税（税从 `getTokenV5` / `FlapTokenTaxSet` 事件读）
**报价要扣费**：卖：`output = diff * (1 - (1% + tax))`；买：`input_after_fee = input * (1 - (1% + tax))`

### 曲线（CDPV2）与进度

```solidity
function getTokenV5(address token) external view returns (TokenStateV5 memory state);
// selector: 0x5c4bc504
// 返回字段顺序（文档）：
//   status, reserve, circulatingSupply, price, tokenVersion, r, h, k,
//   dexSupplyThresh, quoteTokenAddress, nativeToQuoteSwapEnabled, extensionID
```

曲线数学（CDPV2）：
```
supply(eth)  = 1e9 + h - k/(r + eth)
reserve(s)   = k/(1e9 + h - s) - r
price(s)     = k/(1e9 + h - s)^2
progress     = currentReserve / reserveRequired，reserveRequired = reserve(dexSupplyThresh)
```
事件：`FlapTokenProgressChanged`（newProgress 为 wad，1e18=100%）、`FlapTokenCirculatingSupplyChanged`、`TokenBought` / `TokenSold`、`LaunchedToDEX`

## 五、踩坑与教训（重要）

1. **币安接口 chainId 用错会静默返回别的链** —— `CT_501`=Solana、`56`=BSC。看返回地址是不是 `0x` 开头就能立刻发现。
2. **publicnode 限流 403** —— web3.py 的 `HTTPProvider` 不带 UA 会被拒；必须加 `User-Agent` 头，并且**用多节点轮询**（publicnode / 1rpc / blockrazor）。web3.py 的 `wait_for_transaction_receipt` 轮询太密会再触 403 ✗ → 自己写 `eth_getTransactionReceipt` 轮询。
3. **口径必须统一，否则会吵架** —— DexScreener 算的是"上池子之后"的涨幅，币安钱包/ GMGN 算的是"从曲线起始价"的涨幅。同一个币：我说 1.7 倍、大哥看到 20.5 倍（蝴蝶时代）。**以后报价一律以币安口径为准，并说明起算点。**
4. **"筹码集中"不等于"一定砸"** —— 狗哥（`0x949593883d972cd65ef3a0f9548568e2766d7777`）：第一大 51% 时我说"不碰"，结果庄家把 51% 出货到 20%，新资金接盘 → 拉了 4.3~8 倍。**结论：筹码集中是参考项，不是否决项**（极端控盘 ≥85% 才拦）。决定短期的是**资金流入速度**。
5. **Flap 发币事件解码取错字段** —— 新币地址在 **word0**（`data[24:64]`），不是 word1 ✗。取 word1 会把"代币化股票"这类老币（GOOGLB / QQQB / BNCB / DJTB）当新币推。
6. **活跃榜迟到 10+ 分钟的原因有两个**：① cron 间隔（15 分钟 → 已改 5 分钟）② 上榜要攒够地址数（60 个 → 已改分档：<6 分钟的新币门槛降到 20）。
7. **数据陈旧会打脸** —— emo小猴那次给结论时用的是几分钟前的旧读数。**给结论前先刷新数据**。
8. **RPC 读不到就换节点，别停** —— `bc.rpc()` 已有熔断，写交易脚本时也要用它。
