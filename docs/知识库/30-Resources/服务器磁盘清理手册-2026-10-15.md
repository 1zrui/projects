## 命令速查
```bash
# 一眼看大块
sudo du -xsh /* | sort -rh | head
sudo du -xsh /home/ubuntu/* /home/ubuntu/.[!.]* | sort -rh | head -25
# 全部 >100M 的文件
sudo find / -xdev -type f -size +100M 2>/dev/null | grep -vE '^/(usr|proc|sys)'
# docker
sudo docker system df
```
