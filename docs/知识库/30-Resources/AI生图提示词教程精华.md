# AI 生图提示词教程精华

> 来源：知乎《用豆包作图，会这100条提示词就够了》（2026-08-15 抓取整理）
> 定位：豆包/AI 生图提示词方法论与实战指令库

## 万能提示词公式

**主体描述 + 环境光线 + 艺术风格 + 媒介材质 + 拍摄视角 + 精度要求 + 3D 渲染**

拆解：
- **主体描述**：谁/什么东西 + 在什么场景 + 做什么动作
- **环境光线**：自然光/室内光、冷色调/暖色调、柔和/强烈
- **艺术风格**：日系清新、电影感、ins 风、赛博朋克、写实等
- **媒介材质**：胶片感、高清摄影、手绘、质感磨砂等
- **拍摄视角**：平视、俯拍、仰拍、特写、全景
- **精度要求**：8K、超高清、细节拉满、无模糊、无畸变
- **3D 渲染**：光影层次、质感通透、边缘清晰

> 按这个结构写，出图率提升 90%。AI 听不懂大白话，只吃结构化、精准的提示词。

## 单图精修（精选）
- 高清修复，保留细节，提升画质，无模糊无噪点
- 自然提亮，通透感，肤色均匀，不过度磨皮
- 背景虚化，突出主体，景深效果
- 胶片质感，复古颗粒，电影色调
- 清晰五官，锐化细节，头发丝清晰
- 增加光影层次，立体感，不平面
- 柔光滤镜，朦胧感，少女感
- 暗调高级感，黑金色调，低调奢华

## 人像精修（精选）
- 自然美颜，保留皮肤纹理，不假面
- 眼神光，眼睛明亮有神，不呆滞
- 五官立体，鼻影唇色自然，精致淡妆
- 头发丝清晰，不糊边，发色均匀
- 妆容精致，伪素颜，清透底妆
- 港风复古，浓颜系，复古滤镜
- 韩系温柔，浅色系，氧气感
- 日系清新，柔光，干净少年感
- 御姐高级感，冷艳，哑光质感
- 甜美可爱，粉嫩调，元气少女
- 写真精修，杂志风，高级大片感

## 创意风格（精选）
- 赛博朋克，霓虹灯光，未来科技感
- 国潮风，中式元素，鲜艳撞色
- 水墨国风，淡彩写意，古典雅致
- 卡通手绘，Q 版可爱，线条柔和
- 3D 立体，质感通透，光影真实
- 油画质感，笔触细腻，艺术氛围
- 极简风，留白高级
- 水彩手绘，通透晕染，艺术清新
- 像素风，复古游戏，个性趣味

## 文字排版设计（精选）
- 标题醒目，字体清晰，高级简约
- 小红书封面，大字突出，配色和谐
- 电商主图，卖点清晰，吸引点击
- 文字特效，渐变发光，立体质感
- 烫金特效，奢华质感，高端大气

## 核心要点
1. 指令模糊 = 翻车主因（"自然美颜"→塑料脸、"通透质感"→阴间滤镜）
2. 提示词公式七要素按顺序写，别漏
3. 人像重点：皮肤纹理保留、眼神光、发丝清晰、五官自然
4. 风格先定调（日系/韩系/港风/赛博……）再补细节
5. 精度词兜底：8K、细节拉满、无模糊无畸变
