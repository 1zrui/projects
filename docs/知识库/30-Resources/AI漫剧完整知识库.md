## 一、AI漫剧是什么

AI漫剧（AI Dynamic Comics / AI Comic Drama）是一种介于传统动画与真人短剧之间的内容形态：
- **静态漫画画面**为基底 + **镜头运动/缩放/转场** + **配音+音效+BGM**
- 竖屏短视频，单集1-5分钟，适配抖音/快手/B站
- 2025年市场规模突破200亿元，2026年进入工业化阶段

### 核心特征
| 特征 | 说明 |
|------|------|
| 静态→动态 | 漫画分镜添加镜头移动、缩放、转场 |
| AI配音 | 赋予角色声音和情感 |
| 音效音乐 | 场景音效+BGM营造氛围 |
| 竖屏适配 | 适配短视频平台碎片化消费 |

## 二、制作全流程（7步）

```
① 选题/剧本 → ② 角色设定 → ③ 分镜脚本 → ④ 生图(静帧) → ⑤ 图生视频 → ⑥ 配音配乐 → ⑦ 剪辑合成
```

### 每步详解

#### 1. 剧本创作
- **工具**：豆包 / DeepSeek / ChatGPT / Qwen本地
- **要点**：提炼核心剧情，删冗余文字，强化对话和动作
- **格式**：每集有独立小冲突、小闭环，适配1-5分钟节奏
- **Prompt模板**：
```
你是一个专业编剧，写一个3分钟竖屏AI漫剧剧本。
主题：{题材}
要求：
- 场景简洁（减少AI生图难度）
- 对话为主，心理活动转为动作/表情/画外音
- 标注情绪和冲突点
- 每幕标注场景（室内/室外）、人物状态、镜头方向
```

#### 2. 角色设定
- **目标**：确定人物外貌、服装、发型、表情体系
- **关键**：生成「三视图」（正视图+侧视图+后视图）+ 面部特写
- **Prompt模板**：
```
生成全身三视图以及一张面部特写。
最左边占满1/3的位置是超大的面部特写，右边2/3放正视图、侧视图、后视图。
纯白背景，无任何多余元素。
角色描述：{详细外貌描述}
```
- **工具**：即梦AI / ComfyUI+IPAdapter / Midjourney

#### 3. 分镜脚本
- **目标**：把剧本拆成一个个独立镜头
- **每个镜头标注**：镜号、景别（全景/中景/近景/特写）、运镜方向、画面描述、台词、时长、情绪
- **Prompt模板**：
```
你是一个专业动画导演，用中文写一个3分钟竖屏AI漫剧分镜脚本。
主题：{题材}
要求：
- 总12-15个分镜
- 格式：镜号 | 景别/运镜 | 画面描述（50字内） | 台词 | 情绪/特效提示
- 风格：{风格}，高清，角色一致性强
- 角色设定：{角色描述}
输出JSON格式
```

#### 4. 生图（静帧/分镜图）
- **即梦AI**：上传角色参考图 + 输入分镜描述 → 生成静态画面
- **ComfyUI**：IPAdapter + ControlNet + 角色参考图 → 批量生成
- **关键**：每次生成都带上角色参考图，保持一致性

#### 5. 图生视频（让画面"动起来"）
- **即梦 Seedance 2.0**（2026最强）：
  - 首尾帧模式：上传首帧图 + 写prompt
  - 全能参考模式：图片+视频+音频混合输入，用`@素材名`指定用途
  - 核心语法：`@图片1的角色 @图片2的场景` 精准引用素材
- **Wan2.2（通义万相）**：ComfyUI本地运行，角色一致性最强
- **可灵AI**：图生视频，效果稳定
- **LTX 2.3**：ComfyUI节点，精准分镜+时间控制

#### 6. 配音配乐
- **AI配音**：
  - 剪映AI配音（免费，声线多）
  - 魔音工坊（800+声音，付费更接近真人）
  - 海螺AI（支持音色克隆）
  - Qwen3-TTS（本地，ComfyUI集成）
- **音效**：爱给网（免费音效素材库）
- **BGM**：抖音商用音乐库 / 无版权音乐网站
- **三明治音效法**：底层BGM + 中层旁白/对话 + 顶层音效

#### 7. 剪辑合成
- **工具**：剪映（免费首选）/ Premiere / DaVinci Resolve
- **要点**：
  - 按分镜顺序排列镜头
  - 音画同步（台词、音效对齐画面）
  - 添加字幕（一句话一屏，短句优先）
  - 设计封面标题
  - 前3秒必须抓住注意力

## 三、角色一致性（最大难题）

### 2026年最稳方案

| 方案 | 工具 | 难度 | 效果 |
|------|------|------|------|
| ComfyUI + IPAdapter + FaceID + ControlNet Pose | ComfyUI本地 | 高 | ⭐⭐⭐⭐⭐ |
| 即梦「角色参考」功能 | 即梦AI网页 | 低 | ⭐⭐⭐⭐ |
| Midjourney V7 Omni-Reference | Midjourney | 中 | ⭐⭐⭐⭐ |
| Coze工作流一键生成角色卡 | Coze+即梦 | 低 | ⭐⭐⭐ |

### 核心公式
```
新场景描述 + 角色外貌关键词 + 参考图（三视图）
```

### 关键技巧
- 生成3-4张参考图（正面/侧面/表情变化）
- 每次生成都带参考图
- 角色偏离时：新开会话，重新约束
- 多用背影/侧脸/剪影（正脸容易崩）
- 3秒原则：每2-4秒切一次景别

## 五、Seedance 2.0 核心玩法

### 两种入口
1. **首尾帧模式**：一张首帧图 + prompt → 最简单
2. **全能参考模式**（推荐）：图片+视频+音频混合输入

### @语法（灵魂操作）
- `@图片1的角色` → 指定角色参考
- `@图片2的场景` → 指定场景参考
- `@视频1的运镜` → 指定运镜方式
- `@音频1的节奏` → 指定节奏

### 参考素材上限
- 图片：最多9张
- 音视频：各3个
- 混搭最多12个

### 长视频连贯性技巧
- 首尾帧衔接：上一段的尾帧 = 下一段的首帧
- 9/16/25宫格分镜保持一致性
- Coze工作流自动生成多宫格分镜图

## 六、避坑指南

### 常见问题
1. **画面闪烁**：叠加噪点/颗粒滤镜，或加飘花/落叶素材掩盖
2. **节奏拖沓**：3秒原则，每2-4秒切景别
3. **角色崩坏**：多用IPAdapter+FaceID+ControlNet Pose
4. **正脸难画**：多用背影、侧脸、剪影、远景
5. **版权问题**：BGM/音效/字体必须用无版权素材
6. **平台审核**：必须勾选"AI生成内容"标识

### 心态原则
- **完成比完美更重要** —— 先做出来再说
- **先跑60-90秒短片** —— 别上来做长篇
- **观众看故事爽感** —— 不会逐帧检查画面
