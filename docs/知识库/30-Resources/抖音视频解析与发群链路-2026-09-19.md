# 需求

大哥发来抖音分享链，要「解析这个视频然后发群里」。

# 结论：四步链路（唯一能通的路）

```
1. 短链还原   v.douyin.com/xxx 是 302，跟一跳 → www.douyin.com/video/{awemeId}
2. 分享页渲染  打开 https://www.iesdouyin.com/share/video/{awemeId}/
               用【真实 Chrome（非 headless）】等 JS 跑完
               → 从 DOM 的 <video>/<source> 抠出 v26-web.douyinvod.com 直链（playAddr，无水印）
3. 带 Referer 落盘  请求头挂 Referer: https://www.douyin.com/ + 桌面 UA
4. 发群        复用 fb-reels 的 send_group_video
```

实测：短链还原 → 渲染 5s → 抠到直链 → `1288x720 h264 24.7s 7.05MB` → 发群 ok。

# 一条命令

```bash
unset https_proxy http_proxy HTTPS_PROXY HTTP_PROXY ALL_PROXY all_proxy
xvfb-run -a --server-args="-screen 0 1440x900x24" \
  /opt/fb-reels/.venv/bin/python /opt/fb-reels/scripts/dy_to_group.py "<链接或整段分享文本>"
# 只落盘不发群：加 --no-send -o /tmp/out.mp4
```

脚本另存副本：`~/.hermes/skills/media/douyin-video-to-group/scripts/dy_to_group.py`
技能：`douyin-video-to-group`（media）

# 走过的弯路（别再耗时间）

| 做法 | 结果 |
|---|---|
| yt-dlp `-F` / 下载 | ❌ `Fresh cookies (not necessarily logged in) are needed` |
| f2（专做抖音的开源工具，pip 装） | ❌ 403；它自己的 httpx 还报 cookie header 非法字符 |
| 移动端老接口 `api.amemv.com` / `aweme.snssdk.com` / `iesdouyin detail` | ❌ 200 但 **0 字节**（接口已废） |
| `aweme/v1/web/aweme/detail/` 带 a_bogus 签名 | ❌ 403 `Blocked by ArgusSecurityPlugin Uifid Not Found` |
| 页面内 `fetch` detail API | ❌ 卡住 / 403 |
| 第三方解析站 `api.douyin.wtf` / `tikwm` | ❌ NOT_FOUND / 不支持抖音 |
| **分享页 + 真实 Chrome 抠 DOM** | ✅ **唯一通的** |

# 关键教训

1. **headless 必死**。headless Chrome 被抖音检测：页面不渲染、标题空、`_ROUTER_DATA` 里只有页面配置没有视频数据。必须 `xvfb-run` + 真实窗口 + `--disable-blink-features=AutomationControlled`。
2. **走分享页，不是主站**。`www.douyin.com/video/{id}` 直连 curl 返回 **404**（server: volc-dcdn）；`iesdouyin.com/share/video/{id}` 能出内容。
3. **直链带签名+时效**（URL 里 `l=2026...`、`dy_q`、`__vid`），**过期即 403，不能缓存复用**，每次重新解析。
4. **别用境外代理**。走代理会被 ArgusSecurityPlugin 风控（页面空壳）；且 curl 走了代理、浏览器没走会造成 cookie/IP 不配对。服务器出口在国内（腾讯云 119.29.238.30）直连正常。
5. **Chrome 要独立 profile**（`--user-data-dir=/tmp/dy-chrome-profile`）+ `--remote-debugging-port` + playwright `connect_over_cdp`（连真实 Chrome 进程，不是 playwright launch）。
6. **`pkill -f "remote-debugging-port"` 会杀掉执行命令的 shell 自己**（命令行含同样字符串）—— 清理请用具体 profile 名，或干脆不 pkill。
