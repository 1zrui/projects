# 板U套装评估：华硕 PRIME B760M-F D4 + i5-14490F（拼多多百亿补贴 ¥1318）

评估日期：2026-10-11

## 结论
价格不亏，但**搭配有问题**：主板供电压不住这颗 U 的默认功耗。买之前必须决定「降压用」还是「换 12600KF 套装」。

## 实测数据（关键论据）

| 项目 | 数据 | 来源 |
|---|---|---|
| B760M-F D4 供电能力 | **只有 90~100W**（塔式风冷气流辅助下），此时供电区温度 90~100°C | 知乎《华硕B760M-F是什么水平》 |
| B760M-F D4 定位 | 电商整机商专用丐板；B站有《B760M D4 主板避坑指南》专题 | B站 |
| i5-14490F 默认核心电压 | **1.4V**（比 i9-14900K 还高） | 电子工程专辑实测 |
| i5-14490F FPU 烤机（默认） | **206W / 84°C**，P核 4.4GHz | 电子工程专辑 |
| i5-14490F 降压 0.16V 后 | **158W / 66°C**，频率跑满，性能不降反升 | 同上 |
| 官方规格 | 6P+4E / 10核16线程，L3 24MB，基础 65W，最大睿频功耗 148W | Intel ARK |
| 对比 i5-14400F | 单核 +6%，多核 +8%（全核 +300MHz + L3 +4MB） | 多篇评测 |

→ **主板供电 90~100W vs CPU 峰值 206W，差一倍**。这 U 默认给这么高电压，不是主板的问题就是兼容不了。

## 使用建议
- 只游戏/办公：能用的，但**必须进 BIOS 降压**（这 U 是难得能降压的非 K 非 K 处理器）
- **降压也是保命**：13/14 代默认高电压长期跑有「缩缸」（CPU 退化）风险，Intel 老问题
- 渲染/压片/编译/多开：别买，长期满载必撞供电墙降频
- 电费：待机 2~3W 可忽略；默认比降压满载多约 48W，一天满载 4h 一年约 40 元 — 不是钱的问题，是发热和主板寿命
- 华硕 B760 降压路径：BIOS → Actual VRM Core Voltage 改 Manual → CPU Core Voltage Override 设 1.3V 起步 → 关 IA CEP → 解锁功耗墙（Long/Short Duration Package Power Limit 设 9999）→ Cinebench R23 测 30 分钟

## 坑
- 「百亿补贴」的板U套装多为整机商选型，主板普遍选最丐的那块，账面便宜、实际供电缩水
- DDR4 平台 2026-10 正在涨价，D4 省钱优势在缩小
