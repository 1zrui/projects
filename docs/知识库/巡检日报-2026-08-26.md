## 十一、WPS 签到配置

### 脚本来源
- 仓库：`Cat-zaizai/ZaiZaiCat-Checkin`
- 脚本路径：`/ql/data/repo/Cat-zaizai_ZaiZaiCat-Checkin/script/wps/main.py`
- 功能：任务中心签到 + 打卡领会员 + 天天抽奖 + 会员试用申请

### 配置文件
- 位置：`/ql/data/repo/Cat-zaizai_ZaiZaiCat-Checkin/config/token.json`
- 需要的字段：
  - `user_id`：WPS 用户 ID（从 Cookie 的 `uid` 获取）
  - `cookies`：完整 Cookie（必须包含 `csrf`、`wps_sid`、`uid`）
  - `user_agent`：浏览器 UA

### 获取 Cookie 方法
1. 电脑 Chrome 登录 `https://www.wps.cn`
2. 访问活动页面：`https://personal-act.wps.cn/rubik2/portal/HD2024082815116866/YM2024082815122017`
3. F12 → Application → Cookies → `personal-act.wps.cn`
4. 复制 `csrf`、`wps_sid`、`uid` 等值

### 依赖
- 需要安装 `pycryptodome`：`docker exec qinglong pip install pycryptodome`

### 定时
- 每天 10:00 自动执行
- 首次测试结果：打卡签到成功（连续第 1 天），抽奖 1 积分，会员试用 3 项申请成功

### 注意事项
- Cookie 有效期约 7-30 天，过期需重新抓取
- 打卡签到需要绑定手机号
- 连续签到 7 天有额外奖励
