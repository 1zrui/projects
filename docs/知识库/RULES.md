# 知识库规则 (RULES.md)

## 目录结构
- `00-Inbox/` — 新笔记默认入口,待归类
- `10-Projects/` — 进行中的项目
- `20-Areas/` — 长期领域知识(持续维护)
- `30-Resources/` — 参考资料、教程、方法论
- `40-Archive/` — 已完成/不再活跃的内容
- `90-Templates/` — 笔记模板

## 核心规则
1. **新笔记一律先放 `00-Inbox/`**,归类时再移动到对应目录
2. **Inbox 超过 3 天未归类** → 自动归类到最合适的目录
3. 文件名:简短、语义化、用中文,不用日期前缀(除非是日志类)
4. 笔记开头写一行摘要(LLM 友好,方便检索)
5. 相关笔记用 `[[双链]]` 连接,不复制内容
6. 模板统一放 `90-Templates/`,新建笔记从模板复制
7. 图片等附件放笔记同目录的 `附件/` 子文件夹

## LLM 协作规则
- 本文件是库的最高规范,修改需谨慎
- 目录名和结构不得随意改动
- 新建目录需先确认,不擅自创建顶层目录
- 归类不确定时,默认放 `00-Inbox/` 并标注待定

## 巡检约定
- 每日 04:00 自动巡检:扫描变化、Inbox 积压(>3天)、断链、待办
- 有变化推 QQ 日报,无变化静默
