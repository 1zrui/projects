## 关键知识
- **腾讯云不带"清理工具"，最大的垃圾往往在 `.git` 里**：中断的 git 操作会留下 `tmp_pack_*`，单文件几百 MB 且不会被 gc 自动清掉 → 排查磁盘先 `find / -xdev -type f -size +100M`
- tar/du 看 `/var/lib`（docker 镜像层）、`/usr/lib`（LLVM 等大库）、`~/.cache`（各种包管理器缓存）是三个最常见的隐形大户
- 停服务优先用 `systemctl disable --now`（**disable 防重启后再起来**），别只 stop
