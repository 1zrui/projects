# 模型限流踩坑记录（2026-08-25）

摘要：new-api 中转站下 stealth/ox-alpha 与 deepseek-v4-flash 在带工具调用时被上游限流，实测可用模型仅 hy3 与 sensenova-6.8-flash-lite，附诊断方法。

## 现象
- 使用 stealth/ox-alpha 报：`The model provider is rate-limiting requests`（上游 Stealth 共享池限流，is_byok=false）
- deepseek-v4-flash 纯聊天通，但**带 tools 调用**时报 `inference tpm exhausted`（429001）
- 根因：免费模型的公共池被刷爆，不是本地配置问题

## 实测可用矩阵（带 tools 维度，2026-08-25）
| 模型 | 带tools | 结论 |
|---|---|---|
| hy3 | ✅ 通 | 唯一稳的，已切默认 |
| sensenova-6.8-flash-lite | ✅ 通 | 备选 |
| deepseek-v4-flash | ❌ tpm耗尽 | 限流，别用 |
| stealth/ox-alpha | ❌ 上游共享池 | 限流 |

## 诊断方法
直接 curl new-api（`http://127.0.0.1:3000/v1/chat/completions`，带/不带 tools 对比）即可定位是上游还是本地问题。

## 结论
- stealth 和 deepseek 先晾着，等上游池缓过来
- 默认模型已固定 hy3，sensenova 当备选
- 这俩模型不稳，别当主力
