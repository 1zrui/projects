## 2.345yun.cn 脚本库使用经验

### 下载方式
```
curl --noproxy '*' -L "https://2.345yun.cn/api/download/direct/{脚本ID}" -o 文件名
```
- 需要加 `--noproxy '*'` 绕过代理（SSL连接会失败）
- 脚本ID从API获取：`curl --noproxy '*' "https://2.345yun.cn/api/scripts?page=1&limit=500"`

### 脚本筛选标准
- 排除：需要APP抓包、root、curl代码、设备ID的
- 排除：需要充值/付费的
- 排除：需要微信code的
- 优先：手机号#密码登录、下载量>200、有明确收益描述

### 已知问题
- 八富生活广告确认失效（反作弊）
- robomind.vip 域名已挂
- 很多脚本需要APP抓包才能获取token
