# 视觉模型误配修复（2026-08-25）

摘要：Hermes 视觉模型曾被误配为纯文本的 sensenova-6.8-flash-lite，导致所有图片读取失败；改为 glm-4.6v（智谱视觉版）后恢复，附修改方式。

## 故障现象
- 用户发图，视觉模型反复回"没看到图/没有附件"
- 文件本地确实存在（如 130KB~160KB 的 jpg），说明不是图的问题，是模型无视觉能力

## 根因
config.yaml 中：
```
auxiliary:
  vision:
    provider: openai
    model: sensenova-6.8-flash-lite   # 纯文本模型，无视觉能力
```

## 修复
config.yaml 被锁，不能直接 patch，改用 `hermes config set`：
```bash
hermes config set auxiliary.vision.model glm-4.6v
```
验证：`hermes config get auxiliary.vision.model` 返回 glm-4.6v。

new-api 中带视觉能力的候选：glm-4.5-air、glm-4.6v（zhipu_4v 标记）；hy3/deepseek-v4-flash/ox-alpha 均为纯文本，不能当视觉用。

## 验证
改后用本地 jpg 实测，模型能正确描述图片内容（食物照片等），确认恢复。
