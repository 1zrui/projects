## 7. 京东脚本全量排查与批量修复（9-04 凌晨）
- **关键认知**：脚本从青龙 API（5600端口）读 JD_COOKIE，docker exec 直接跑 node 读不到 → 全部假失败。正确做法：走青龙 API 触发任务（与面板手动运行一致）
- 批量触发 API：`PUT /api/crons/run`，body 是**纯数组** `[id1,id2,...]`
- 禁用 API：`PUT /api/crons/disable`，body 纯数组 `[ids]`；启用：`PUT /api/crons/enable`
- 更新调度 API：`PUT /api/crons/`，body 需带 `{id, command(必填), schedule, name}`
- 触发测试结果：CK 有效（检测显示状态正常），40+任务正常完成，天天赚京豆实得 37 京豆
