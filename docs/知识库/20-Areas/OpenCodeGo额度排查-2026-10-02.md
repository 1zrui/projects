- 注：13:29 日志里的 `user 0 | Invalid token` 是本次排查自己打的可达性测试，非外部攻击

## 三、结论与建议（待大哥定）
1. **不是被偷用**：OpenCode Go 的额度就是云上 Hermes 自己消耗的（主模型走 ch31）。要么接受，要么换。
2. **止血方案**：把云上 Hermes 主模型从 `deepseek-v4.1-flash`（ch31）换到免费渠道（商汤 8 把 key 的 `deepseek-v4-flash` / `glm-5.2`、AMD `DeepSeek-V4-Flash`、b.ai），OpenCode Go 只留给 OpenCode CLI 写代码用。
3. **处理「韩」令牌**：确认来源，不明就禁。
4. **加固**：3000 只绑 `127.0.0.1`（或 ufw 白名单源 IP）+ 令牌配置 `allow_ips`；管理端密码检查。
5. **终极确认**（可选）：opencode.ai → **Logs** 标签页看请求来源 IP，若全是本服务器出口，则完全闭合。
