# 服务器磁盘空间清理（2026-08-26）

摘要：40G 磁盘占用 17G（45%），拆解各目录构成，清理安全项回收约 1.5G，明确不可动的核心目录。

## 磁盘构成（16.8G 时）
- 个人数据/项目 ~8.9G：quant-trading(983M,其中 venv 979M)、.hermes(1.7G)、.cache(1.6G 浏览器驱动)、.local(1.4G)、workspace 其他、fb-reels-tmp(224M)、app/new-api(133M)
- 系统层 ~7.9G：/usr(5.4G)、/var(1G)、/opt(769M)、/tmp(467M)、/boot(200M)

## 已清理（安全，零风险）
1. fb-reels-tmp 224M — 早不用的临时目录
2. .cache/google-chrome-headless 27M — 浏览器残留
3. .cache/pip + .cache/uv 共 594M — 下载缓存
4. .npm/_cacache 218M — npm 缓存
5. /tmp 死文件 — 跳过 root 锁定的 tlinux_xps.log

净回收约 1.5G，17G→16G，可用 22G（43%）。

## 不可动（删了环境废）
- quant-trading/venv（979M）— 回测环境，重建成本高
- .hermes 整套 — Hermes 本体
- /usr /var /opt /boot — 系统核心

## 提醒
磁盘"涨很多"多为 venv/浏览器驱动/系统库等一次性存量，非近期突发增量；真实近期增量（new-api 日志、截图缓存）仅几十 M。
