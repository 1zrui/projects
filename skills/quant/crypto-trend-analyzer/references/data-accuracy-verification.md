# 数据准确性交叉验证（2026-08-20 实战）

> 用户问"数据准确吗"时的标准回答流程。技能本身算出的 RSI/EMA/量比是否可信，取决于源数据新鲜度。

## 交叉验证三步

1. **Ticker vs K线收盘价**
   ```bash
   curl -s -x socks5h://127.0.0.1:10808 "https://api.binance.com/api/v3/ticker/price?symbol=ETHUSDT"
   # 对比 1h K线最后1根 close，二者差值应 < 0.5% 且时间戳 < 2*周期
   # 2026-08-20 11:14 实测：ticker 2228.13 vs K线收盘 2227.61，差0.5刀，正常（11:00这根未收盘）
   ```
2. **24h 高低点一致性**
   ```bash
   curl -s -x socks5h://127.0.0.1:10808 "https://api.binance.com/api/v3/ticker/24hr?symbol=ETHUSDT"
   # 高 2333.65 低 1906 应与 1h/4h 摆动点一致
   ```
3. **多周期自洽**
   - 15m 最后2根 2251.89→2227.85 正在跌，应与 1h 趋势"弱多头但缩量"自洽
   - 若 15m 已转弱空头(RSI49.3)而 1h 仍显示强多头 → 标注"周期背离"，不强行统一

## 时效性陷阱

- ETH 10:31 $2258 → 11:14 $2227 → 11:20 $2254，45分钟波动30刀，报告必须带时间戳 `YYYY-MM-DD HH:mm`
- 不带时间戳的分析=过时分析，禁止复用旧报告

## 公式校验

- RSI 必须 Wilder 平滑，简单平均会虚高 5-10 点
- 2026-08-20 ETH 1h RSI 84.1 vs 4h RSI 93.0，跨周期一致才可信
